# Team Spirit — Dragon Quest Quiz

Одностраничная мобильная викторина: видео-интро → 10 вопросов → результат с цветовой
шкалой и лимитом перепрохождений.

Статика без бэкенда — vanilla JS (ES-модули), никаких зависимостей и шага сборки.
Всё состояние живёт в `localStorage` браузера игрока.

## Запуск

Нужен любой статический сервер — из-за ES-модулей открыть `index.html` как `file://`
не получится (CORS).

```bash
cd app
python3 -m http.server 8000
# http://localhost:8000/
```

## Тесты

```bash
cd app
npm test          # node --test tests/
```

Покрыты чистые функции: подсчёт очков, границы бандов, политика ретраев,
персистентность состояния (включая повреждённый и недоступный localStorage).

## Как это устроено

```
app/
  index.html          все три экрана сразу в разметке, переключаются через [hidden]
  js/app.js           рендер, роутинг между экранами, обработчики
  js/quiz-logic.js    чистые функции: score / band / retriesAllowed / retriesLeft
  js/state.js         обёртка над localStorage, переживает refresh посреди квиза
  js/i18n.js          все тексты интерфейса
  data/questions.js   вопросы и индексы правильных ответов
  css/main.css        дизайн-система из макета
  assets/             шрифты, изображения, видео-интро
deploy/
  deploy.sh           атомарная выкладка по SSH
  nginx.conf.example  vhost: кэш-политика, security-заголовки, CSP
```

### Правила игры

| Результат | Цвет | Попыток перепройти |
|---|---|---|
| 0–5 | красный `#900e0e` | 1 |
| 6–8 | жёлтый `#ffb916` | 2 |
| 9–10 | зелёный `#1ed94b` | — финальный экран |

Оставшиеся попытки считаются как
`max(0, allowed(band) - (attemptsUsed - 1))` — то есть банд пересчитывается после
каждой попытки, и улучшение результата меняет лимит.

### Порядок вариантов

Варианты перемешиваются при каждом показе (`app.js`), потому что в исходном
документе с вопросами 9 из 10 правильных ответов были первым вариантом. В
`answers` сохраняется исходный индекс, не позиция на экране.

### Админ-режим

`/?admin` показывает кнопку полного сброса состояния — для человека,
который стоит рядом со стендом на ивенте.

### Видео-интро

`app/assets/video/intro.mp4`. Блок сам скрывается, если файла нет
(`app.js` проверяет HEAD-запросом), так что репозиторий остаётся рабочим без него.

Если будете менять ролик: исходники с айфона приходят в HEVC, с поворотом в
метаданных и в full-range цвете — под веб нужно перекодировать, иначе часть
мобильных браузеров покажет либо боком, либо выцветшим:

```bash
ffmpeg -i IMG.MOV -c:v libx264 -profile:v high -pix_fmt yuv420p -crf 23 -preset slow \
  -color_range tv -c:a aac -b:a 128k -movflags +faststart app/assets/video/intro.mp4
```

Вёрстка рассчитана на вертикальный кадр 9:16; при другом соотношении сработает
`object-fit: contain` и по краям появятся поля — тогда поправьте `max-width`
у `video` в `main.css`.

## Деплой

```bash
DEPLOY_HOST=myserver ./deploy/deploy.sh
```

Кладёт содержимое `app/` в `/var/www/teamspirit-quiz` (переопределяется через
`DEPLOY_DIR`). Выкладка атомарная — распаковка идёт в `.new`, потом каталоги
переставляются; предыдущая версия остаётся в `.old`, откат это один `mv`.

Nginx: см. `deploy/nginx.conf.example`. Одна нетривиальная деталь — `add_header`
внутри `location` полностью перекрывает заголовки уровня `server`, поэтому
security-набор продублирован в каждом блоке. HTML и JS отдаются с `no-cache`,
чтобы правки доезжали сразу; шрифты и медиа — с недельным кэшем.

## Сторонние материалы

Шрифт **JMH Typewriter** (`app/assets/fonts/`) — сторонний, предоставлен для этого
проекта. Логотипы, `paper.jpg` и `stamp.png` — брендовые материалы Team Spirit.
Перед использованием за пределами этого проекта проверьте условия лицензий.
В CSS прописан фолбэк `'Courier New', monospace`, так что без файлов шрифта
приложение остаётся читаемым.
